Food and Beverage Sales Analysis Dashboard
Overview

This project is a Power BI dashboard designed to analyze and visualize food and beverage sales data. It provides insights into sales performance, revenue trends, product categories, customer behavior, and profitability through interactive reports and visualizations.

The dashboard enables businesses to track important KPIs and make informed business decisions using data-driven insights.

Interactive Power BI dashboard

Revenue and profit tracking
Product category insights
KPI cards for quick business overview
Trend analysis using charts and graphs
